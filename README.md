# 📱 My Goals – Aplicativo de Gerenciamento de Metas Pessoais

Desenvolvido como projeto de livre escolha pelos alunos:  
**Kleberson Crystyan de Lima, Vinicius Fernandes Betti, Gabriel Henrique Custódio, Vitor Hugo Granato Moreira do Prado**

---

## 🎯 Objetivo do Projeto

O projeto **"My Goals"** tem como finalidade oferecer uma aplicação prática, intuitiva e moderna para o gerenciamento de metas pessoais. Desenvolvido em Android (Java), o app proporciona ao usuário a experiência de registrar, visualizar e controlar seus objetivos de forma eficiente e agradável.

---

## ✅ Requisitos Atendidos

Conforme os critérios propostos para o projeto de livre escolha, o grupo atendeu integralmente os seguintes requisitos:

- ✅ **Interface com botões e textos:** layout moderno e funcional, com botões para ações principais (adicionar, limpar) e campos de entrada amigáveis.
- ✅ **Persistência de dados local:** banco de dados SQLite integrado para garantir que as metas sejam armazenadas permanentemente.
- ✅ **Design atrativo:** interface construída com paleta de cores vibrantes e elementos visuais modernos, incluindo emojis para estados especiais (vazio ou conclusão).

---

## 🚀 Funcionalidades Implementadas

- Cadastro de metas com data de criação automática.
- Marcação de metas como **concluídas** por meio de checkboxes com efeito visual.
- Contador dinâmico de metas exibido no cabeçalho.
-  Botão para **limpar todas as metas concluídas** com um clique.
-  Exibição de **estado vazio**, com emoji e mensagem personalizada, quando não há metas registradas.
-  **Persistência total** de dados: metas permanecem salvas mesmo após o encerramento do aplicativo.

---

## 📱 Detalhes da Interface

- **Header azul:** exibe o título do aplicativo e o número atual de metas ativas.
- **Seção de entrada:** campo de texto e botão para adicionar novas metas.
- **Lista de metas:** exibe os objetivos com status visual e checkboxes.
- **Mensagem de estado vazio:** interface personalizada exibida quando não existem metas cadastradas.
