# My Goals

Aplicativo Android para gerenciamento de metas pessoais. Projeto de livre escolha desenvolvido em grupo.

## Funcionalidades

- Cadastro de metas com data de criação automática
- Marcação de metas como concluídas
- Contador de metas ativas no cabeçalho
- Remoção de todas as metas concluídas com um toque
- Estado vazio com mensagem dedicada
- Persistência local: as metas permanecem após fechar o app

## Tecnologias

- Java
- Android Studio
- SQLite

## Executar

1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo Android.
